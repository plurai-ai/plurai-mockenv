# Contributing

Issues are welcome: bug reports, questions and suggestions all help. Please include the
`plurai-mockenv` version, your Python version and a minimal reproduction.

This repository does not accept outside pull requests; only the maintainer team can open them.
Open an issue and describe the problem or the change you have in mind instead.

To report a security problem, follow [SECURITY.md](SECURITY.md) and do not open a public issue.
